# 联机协议长期分支

新联机协议在 `codex/authoritative-v7` 开发，应用版本为 `2.2.0`，协议版本为 `7`。`main` 继续维护 1.x，两条线使用独立工作目录。

本分支包含权威服务器、时间线客户端、地图缓存、原生引擎容量优化、协议规范和验收工具。原版 176 联机模式独立保留。新协议不会通过运行时开关或定期合并进入 1.x；需要回移的通用修复应逐项审查、单独移植。

迁移时先保存完整未提交内容及文件指纹，再将独立的 emoji、个人设置持久化和任务排空修复与协议改动分成两次提交。1.x 工作目录保留这些独立修复，分支指针和原有暂存状态不变；版本号恢复为该目录原有的 `1.4.3`。历史验证记录中的版本号与指纹没有重写。

实验构建使用 `RWXX-Timeline` 安装名，桌面用户数据使用 `rwx-timeline` 目录，Android 应用 ID 使用 `io.github.rwx.timeline`。它们与 1.x 的安装和用户数据分开。显式指定的便携目录或测试目录仍由调用者控制。

协议构建、冻结候选、采样、测试输出和未完成的优化候选一起迁到协议工作目录。历史脚本中的旧绝对路径只记录当时的运行位置；后续运行应从当前工作目录定位仓库，不能让脚本指回 1.x。

65,536 个活动单位、64 席位、60 Hz 的完整链路验收仍未通过。当前状态和证据见[设计与验收记录](authoritative-v7-design.md)。分支拆分不会改变验收目标，也不代表新协议已经完成发布验收。
