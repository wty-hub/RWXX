RWXX 相对原版《铁锈战争》的主要改进

版本：RWXX 1.4.0
整理日期：2026年10月31日
比较基准：官方原版《铁锈战争》。本清单包含从 RWX 继承的增强，以及 RWXX 新增和完善的功能。

1. 彩色 emoji 显示
大厅列表、房间聊天接入彩色表情显示，处理国旗、肤色、组合表情和连续表情，改善空白、拆散或显示成字母的问题。此项覆盖已接入的界面入口，不代表所有游戏内文字位置均已支持。

2. 中文输入
接入系统输入法，改善候选框位置、光标和选区同步、输入结束后的焦点恢复，并处理 Linux fcitx5 兼容问题。

3. 聊天体验
房间新消息自动滚到底部；改善对局聊天折行、发送后清空和再次打开输入框；修复滚动弹窗时误缩放地图等问题。

4. 界面与汉化
重做主菜单、大厅、房间、设置和暂停菜单，补齐中文显示；提供游戏内多套配色，以及 HUD 和建造菜单缩放。

5. 回放控制
支持拖动时间轴定位、前后跳转10秒、暂停和调整播放速度；增加玩家视野和迷雾显示控制。

6. 生产与操作
多工厂可选“全部工厂生产”或“单个单位生产”，优先空闲、短队列工厂；完善编组操作、快捷键设置和冲突提示。

7. P2P 联机
增加 P2P 大厅、房间 ID 加入，以及 WebRTC、libp2p 等连接路径。实际连通取决于网络和服务配置，不能保证所有网络环境均能连接。

8. 区域控制玩法
支持占领区域、持续得分、目标分数胜利，配套区域显示、编辑和状态保存；用于单机或支持该功能的 P2P 对局。

9. JVM 模组扩展
在原有单位模组之外，增加代码模组、扩展 API、生命周期管理和独立卸载。涉及仿真的扩展仅在单机或 P2P 对局中开放，回放和普通原版联机中禁用。

10. 资源浏览器
支持在游戏内搜索地图、模组，查看周下载排行，并下载到对应目录。此功能依赖第三方资源服务及有效的下载地址。

11. 桌面适配
改善高 DPI、窗口尺寸、macOS 原生全屏、黑屏和焦点问题，并提供自带 Java 运行时的桌面包。

12. 性能与资源管理
统一桌面渲染链路，分离引擎与渲染线程，优化地图缓存和碰撞查询，复用纹理、文字网格、像素数组及上传缓冲。
协调画面生产与呈现目标，减少忙等，后台降低呈现频率。桌面自动档上限为300 FPS，失焦、隐藏或最小化时呈现上限为30 FPS；上限不代表实际帧率。

当前限制

地图联通目前仍被代码关闭，属于开发中功能，不能计为现成可用的改进。

性能优化主要集中在桌面端，不能直接推断 Android 的性能表现。现有验证尚未证明所有场景都比原版更流畅；快速连续拖动和缩放、物理输入延迟、长时间对局流畅性，以及历史 DirectBuffer 内存耗尽问题仍未完成验收。
